SHODAN 数值编辑器 v3.2.0（魔改整合版）变更说明
==================================================

基线：上游 SHODAN Stat Editor Offline v3.2.0（提交 0e80317）＋ 我们的军械库魔改线。

一、本版修好了「改射弹 ID 不生效」
1. 单块数据表里没有任何别的块可借盐，改一个 u32（射弹 ID、爆炸 ID、破片数量）时旧版会报
   nothing to vary for the hash，并整体中止安装 —— 表面现象就是「射弹 ID 改了没反应」。
   本版会借用邻近的一个浮点数，在自身值的千分之一以内移动它来配平哈希，安装正常完成，
   被借用的数值仍在游戏本身的噪声范围内。
2. 数据文件被别的 mod 或工具改过时，旧版会整张表拒绝加载（日志写 changed by another tool），
   射弹 / 爆炸 / 伤害 / 实体 / 战备五张表直接消失，面板里连射弹行都没有。本版改为在别人的
   改动之上继续构建（沿用上游 3.2.0 的做法），并保留我们自己的哈希修正。

二、上游 3.2.0 带来的功能（本版已包含）
- 所有战备都可手动选择（含任务与总统奖励战备）；堆叠被动最多 3 条效果并显示描述；
- 投掷物引信时间、载具再生与延迟、伤害与状态效果选择器；
- 窗口按屏幕尺寸初始化并记忆位置；
- 更新器搬进 shodan_hash.dll（自带解压、替换、重启、清理）。

三、本 Fork 的差异功能
- 军械库页：护甲被动、载具部件血量与护甲（逐部件行）。
- 搜索框支持中文 / 繁体 / 俄文名称匹配，可直接用输入法打字（走 WM_CHAR，不再依赖按键轮询）。
- 窗口可自由缩放，底部按钮栏按窗口宽度自动排版。
- 附带 MCP 服务器（mcp/stat_editor_mcp.py），给 AI 助手读改数值用；--game 可指向数据副本。
- 更新源指向本 Fork 的 Releases，点「更新」不会把魔改版换回原版。

四、使用注意
- 请先关闭游戏，再点「安装到游戏」；装完再启动游戏。
- 原版文件备份在 %LOCALAPPDATA%\SHODAN\StatEditor\originals，可用「还原游戏文件」一键恢复。
- 未签名程序首次运行可能被 SmartScreen 或杀软提示，属正常现象。
