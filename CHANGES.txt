SHODAN 数值编辑器 v3.2.3（魔改整合版）变更说明
==================================================

基线：上游 SHODAN Stat Editor Offline v3.2.0（提交 0e80317）＋ 我们的军械库魔改线。

一、修掉「改过的射弹从记录页消失」（本版核心，群友反馈）
1. 症状：在记录页把某个弹丸的数值改好、安装之后，下次打开修改器，这一条就从「记录」列表里消失，
   用搜索栏也搜不到，总数比正常少。实测 #105（GP-20 最后通牒）与 #277（12.5mm EIT）都中招。
2. 原因：安装收尾时会把「这次动过的对象」统一重新解析一遍；而记录页（弹丸 / 爆炸 / 状态记录）也被
   当成武器重新解析，于是它的行被清成 0。列表只收录「有行」的页，于是这一页永久掉出列表与搜索。
3. 修法：记录页不再走武器解析；页的行改成「表没读完或读取出错时保留原有行」；空页不再进缓存；
   全表重扫期间不重建页。四处改动都在 src/stat_editor_offline.lua。
4. 结果：改过的射弹稳定留在「记录」页，存档值照常写进表里（实测 drag 0.1、calibre 20 都在）。

二、新增回归测试
1. tests/test_record_pages.py：用真实游戏表 + 一份带记录页存档值的配置跑无窗口面板，
   断言 #105 / #277 建出 48 行、留在 355 条射弹列表里、表消失一帧也不会被清空，
   且它们的存档值真的落到了行上、日志里没有「has no stat」的拒绝记录。
2. tests/run_headless.py 支持 GAME_DIR 环境变量指向干净的游戏目录副本（实机表里带着玩家自己的改动时，
   它末尾那条「与原始数据逐字节比对」的断言会失败，属于预期）。

三、v3.2.2 的内容原样保留（近炸引信、爆炸角 360、MCP 字段、v3.2.1 的记录页补齐与 UI 修复）。

SHODAN 数值编辑器 v3.2.2（魔改整合版）变更说明
==================================================

基线：上游 SHODAN Stat Editor Offline v3.2.0（提交 0e80317）＋ 我们的军械库魔改线。

一、近炸引信终于能用了（本版核心）
1. 「爆炸接近度」（射弹记录 +148）以前改大不生效，原因是两个字段必须一起改：爆炸阈值角（+136）要 360，
   接近度（+148）要够大。实机验证：CB-9 爆燃弩 3 米 / 80° 完全没反应，改成 360° + 6 米后弩箭在飞行中起爆。
2. 射弹记录页的「爆炸角」上限从 180 放宽到 360（原来根本打不进 360，而 RL-77、等离子这类空炸弹用的就是 360）。
3. 武器页新增「爆炸角」一行，改枪时不用再跳到记录页。
4. 「爆炸角」「爆炸接近度」的说明里写进了实测结论，包括「半径建议大于初速/游戏帧率」
   （500 米/秒的弩箭在 120 Hz 下每帧走 4.2 米，3 米的球会被直接跨过去）。
5. 记录页 +140 的标签改为它的真名「撞击后可失效」（0 = 穿过去的 flak / 集束弹，1 = 其它），中/繁/俄三语同步。

二、MCP 服务器补齐射弹字段
1. 新增 blast_angle、fuse_proximity、fuse_delay、arming、sim_steps、lifetime_random、max_ricochets 等字段，
   现在可以直接用命令行写近炸引信，不必开面板。
2. 修正旧错误：lifetime 以前读的是 +56（随机寿命），现在读 +52，+56 归 lifetime_random。

三、v3.2.1 的内容原样保留（记录页字段补齐、宽窗口按钮与滚动条修复、单块表借盐修射弹 ID 等）。
SHODAN 数值编辑器 v3.2.1（魔改整合版）变更说明
==================================================

基线：上游 SHODAN Stat Editor Offline v3.2.0（提交 0e80317）＋ 我们的军械库魔改线。

一、记录页补齐游戏自带数据里的字段（本版新增）
1. 射弹记录页按「投掷 / 碰撞与贴花 / 跳弹 / 效果 / 音效 / 标志位」分节，补上：模拟步数、寿命、随机寿命、
   穿透衰减、贴花尺寸、表面碰撞类型、跳弹碰撞类型、撞击标志、推进器特效时长、最大跳弹数，以及跳弹整组
   （阈值角度、阈值速度、角度损失、垂直散布、水平散布）；效果与音效两组共 7 行（命中效果伤害类型、火焰模板、
   状态效果体积模板、射线模板，跳弹音效 / 尾迹音效起止三个事件）；再加 +244 标志位（位域整体数值 + 两位
   已知含义：继承速度、爆炸继承速度）。
2. 修正一处旧错误：射弹页原来把 +56（随机寿命）当「寿命」显示，现在寿命读 +52、随机寿命读 +56。
3. 爆炸记录页新增「效果」分节：地形形变（即弹坑类型）、表面碰撞类型、命中效果伤害类型、噪音模板、
   风效模板、火焰模板、状态效果模板、电弧类型。
4. 武器页新增模拟步数、寿命、随机寿命、最大跳弹数四行。
5. 枚举类字段显示游戏自己的编号：当前数据里没有枚举名表，面板不编造名字。

二、界面两处修复（本版新增）
1. 宽窗口下数值列右侧的 -- / - / + / ++ / R 五个按钮点不动：数值行的点击区域盖在按钮上面，
   现在先注册行区域、再注册按钮，五个按钮正常响应。
2. 宽窗口下滚动条和上移 / 下移按钮停在旧位置：现在与数值列一起随窗口宽度右移。

以下是 v3.2.0（上一版）就有的内容，本版原样保留：

基线：上游 SHODAN Stat Editor Offline v3.2.0（提交 0e80317）＋ 我们的军械库魔改线。

一、本版修好了「改射弹 ID 不生效」
1. 单块数据表里没有任何别的块可借盐，改一个 u32（射弹 ID、爆炸 ID、破片数量）时旧版会报
   nothing to vary for the hash，并整体中止安装 —— 表面现象就是「射弹 ID 改了没反应」。
   本版会借用邻近的一个浮点数，在自身值的千分之一以内移动它来配平哈希，安装正常完成，
   被借用的数值仍在游戏本身的噪声范围内。
2. 数据文件被别的 mod 或工具改过时，旧版会整张表拒绝加载（日志写 changed by another tool），
   射弹 / 爆炸 / 伤害 / 实体 / 战备五张表直接消失，面板里连射弹行都没有。本版改为在别人的
   改动之上继续构建（沿用上游 3.2.0 的做法），并保留我们自己的哈希修正。

二、上游 3.2.0 带来的功能（本版已包含）
- 所有战备都可手动选择（含任务与总统奖励战备）；堆叠被动最多 3 条效果并显示描述；
- 投掷物引信时间、载具再生与延迟、伤害与状态效果选择器；
- 窗口按屏幕尺寸初始化并记忆位置；
- 更新器搬进 shodan_hash.dll（自带解压、替换、重启、清理）。

三、本 Fork 的差异功能
- 军械库页：护甲被动、载具部件血量与护甲（逐部件行）。
- 搜索框支持中文 / 繁体 / 俄文名称匹配，可直接用输入法打字（走 WM_CHAR，不再依赖按键轮询）。
- 窗口可自由缩放，底部按钮栏按窗口宽度自动排版。
- 附带 MCP 服务器（mcp/stat_editor_mcp.py），给 AI 助手读改数值用；--game 可指向数据副本。
- 更新源指向本 Fork 的 Releases，点「更新」不会把魔改版换回原版。

四、使用注意
- 请先关闭游戏，再点「安装到游戏」；装完再启动游戏。
- 原版文件备份在 %LOCALAPPDATA%\SHODAN\StatEditor\originals，可用「还原游戏文件」一键恢复。
- 未签名程序首次运行可能被 SmartScreen 或杀软提示，属正常现象。
